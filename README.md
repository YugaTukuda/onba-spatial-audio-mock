# ONBA — コガネムシ 空間音響モック

10m × 10mの空間に録音を配置し、ヘッドホンで試聴する静的なモックです。

初期音源は「コガネムシ.m4a」の00:00–00:30、00:30–01:00、01:00–01:30の3本。各30秒です。元録音の全体は含めていません。

- クリックとドラッグで音源・鑑賞者を移動
- WASDで移動、Q/Eまたは左右矢印で回転
- 音量・音声ファイル・高さの調整、シーンの保存と復元
- Web Audio HRTF、距離減衰、簡易な壁面反射・残響
- 端末内のMediaPipeによる顔向き推定

有料API・データベース・独自ドメインは使いません。持ち込んだ音声やカメラ映像はブラウザ内で処理します。

MediaPipeのライセンスは vendor/MEDIAPIPE-LICENSE.txt を参照してください。

## 会場の反響

「会場の条件を調整」で天井高、壁・床・天井の吸音率、残響時間RT60（自動・手動）、プリディレイを設定できます。ダイアログ内でも再生・一時停止と響きの強さを調整できます。

初期状態は10m × 10m × 高さ3mのホワイトキューブを仮定し、吸音率は壁10%・床5%・天井10%、推定RT60は約1.71秒です。これらは試聴の出発点となる仮の値で、実測値ではありません。壁4面・床・天井の一次反射と、RT60に応じた拡散残響を合成します。

自動RT60はEyring式による帯域平均の概算です。実際の会場の周波数特性・遮蔽物・回折は解析しません。会場パラメータはシーン保存に含まれます。参考：[Arup Strutt / Reverberation Time](https://strutt.arup.com/help/Building_Acoustics/RTInsert.htm)。

`node tests/acoustics.test.mjs` で数式・鏡像音源・減衰包絡・シーン互換性を検証できます。`tests/room-checks.html` はHTTPサーバー経由で使う、無音出力のWeb Audio検証です。
