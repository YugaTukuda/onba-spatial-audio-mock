# ONBA — コガネムシ 空間音響モック

10m × 10mの空間に録音を配置し、ヘッドホンで試聴する静的なモックです。

初期音源は「コガネムシ.m4a」の00:00–00:30、00:30–01:00、01:00–01:30の3本。各30秒です。元録音の全体は含めていません。

- クリックとドラッグで音源・鑑賞者を移動
- WASDで移動、Q/Eまたは左右矢印で回転
- 音量・音声ファイル・高さの調整、シーンの保存と復元
- Web Audio HRTF、距離減衰、簡易な壁面反射・残響
- 端末内のMediaPipeによる顔向き推定

有料API・データベース・独自ドメインは使いません。持ち込んだ音声やカメラ映像はブラウザ内で処理します。

MediaPipeのライセンスは vendor/MEDIAPIPE-LICENSE.txt を参照してください。
